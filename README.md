# KGC Automation

One-page website for KGC Automation (Brugg AG): automations for Swiss businesses.

- Live site: `index.html` (built file, served by GitHub Pages)
- Source: `src/` (base styles, shared data in `src/core.js`, one folder per section in `src/sections/`)
- Rebuild after editing source: `python3 build.py` then copy `dist/index.html` to the repo root.
